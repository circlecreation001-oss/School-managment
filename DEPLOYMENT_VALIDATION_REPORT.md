- key: SMTP_FROM_NAME
  value: SchoolNex

### 2. DATABASE_URL Must Use Direct Connection

Prisma transactions (used in signup) require a direct PostgreSQL connection, NOT PgBouncer:

```
DATABASE_URL=postgresql://postgres:[PASSWORD]@db.[PROJECT_REF].supabase.co:5432/postgres
```

The pooler URL should be set as DIRECT_URL:

```
DIRECT_URL=postgresql://postgres.[PROJECT_REF]:[PASSWORD]@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres?pgbouncer=true
```

### 3. Build Command Must Generate Prisma Client

Current render.yaml has:
```yaml
buildCommand: npm install && npx prisma generate --schema=packages/database/prisma/schema.prisma && npm run build:api
```
This is correct ✅

## Deployment Steps (Manual - Not Automated)

### Step 1: Deploy Backend to Render

1. Push latest code to GitHub:
   ```bash
   git push origin main
   ```

2. Create a new Web Service on Render:
   - Connect to GitHub repo `circlecreation001-oss/School-managment`
   - Root Directory: _(leave empty - monorepo root)_
   - Build Command: `npm install && npx prisma generate --schema=packages/database/prisma/schema.prisma && npm run build:api`
   - Start Command: `node apps/api/dist/server.js`
   - Health Check Path: `/api/v1/health`

3. Set ALL environment variables in Render dashboard:
   - DATABASE_URL (direct connection)
   - DIRECT_URL (pooler connection)
   - REDIS_URL (Upstash)
   - JWT_ACCESS_SECRET (64-char random hex)
   - JWT_REFRESH_SECRET (64-char random hex)
   - ENCRYPTION_KEY (32-char random hex)
   - CORS_ORIGINS (Vercel domain)
   - SUPER_ADMIN_EMAIL
   - SUPER_ADMIN_PASSWORD
   - SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS

4. Deploy → Get Render URL (e.g., `https://education-erp-api.onrender.com`)

### Step 2: Run Database Migrations

After deployment, run:
```bash
npx prisma migrate deploy --schema=packages/database/prisma/schema.prisma
```
Or if already in sync:
```bash
npx prisma db push --schema=packages/database/prisma/schema.prisma
```

### Step 3: Seed Database (Optional)

```bash
npm run db:seed
```
Creates roles, permissions, and super admin account.

### Step 4: Deploy Frontend to Vercel

1. Go to Vercel → Import Project
2. Connect to GitHub repo `circlecreation001-oss/School-managment`
3. Root Directory: `apps/web`
4. Framework: Next.js (auto-detected)
5. Environment Variables:
   - `NEXT_PUBLIC_API_URL` = `https://your-render-app.onrender.com/api/v1`

6. Deploy → Get Vercel URL

### Step 5: Update CORS

In Render dashboard, set:
```
CORS_ORIGINS=https://your-app.vercel.app
```
